
# Obsidian Brain Guide

## Access Personal Token

For create a new personal access token, access the git, click at profile picture and select settings.
Go to Developer Settings on aside menu, and create a classic token. Setup with all repo permissions.


### Setup Obsidian

Install the default themes: (optional)

- `Royal Velvet`
- `Blur`

Install and enable the Plugins:

- `Git plugin`
- `Advanced Canvas`
- `background image`



### background setup

Open the background image plugin, past the URL and substitute the tag areas from the image data:

Add English language to spellcheck languages, on option access the Editor on aside menu, and in behavior section
add English version



### Clone Remote Repo

In obsidian press CTRL+P and search for clone git command.
Type the url, and substitute the tag areas from your data:

```
https://<PERSONAL_ACCESS_TOKEN>@github.com/<REPO>.git
```

Type de name folder, and after select if you want deep cloning.
