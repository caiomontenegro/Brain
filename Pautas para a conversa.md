Bug- Relatório Expresso de Cobrança.

Quando o usuário tentava gerar um relatório de API, e selecionava como origem de aplicação, uma aplicação tem o mesmo nome de outra aplicação na mesma conta, o relatório gerava apenas as cobranças de uma das aplicações. 

Ou seja, caso o usuário possua mais de uma API's com o mesmo nome, caso ele tentasse gerar um relatório de cobrança com esse nome, o relatório exibia as cobranças de apenas uma dessas API's.
